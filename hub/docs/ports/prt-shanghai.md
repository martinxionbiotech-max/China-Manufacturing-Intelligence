# Shanghai Port

**上海港** — *Port*

- **City:** Shanghai
- **Province:** Shanghai
- **Serves clusters:** [Shanghai Integrated Circuits Cluster (Zhangjiang)](../clusters/cls-shanghai-ic.md), [Shanghai NEV Cluster](../clusters/cls-shanghai-nev.md), [Shanghai Zhangjiang Biopharma Cluster](../clusters/cls-zhangjiang-biomed.md)

## Verified facts

- 2024年上海港集装箱吞吐量首次突破5000万标准箱，创全球港口集装箱运输史上最高纪录，连续15年蝉联全球第一。  
  *Source: 上海市国资委/国务院国资委(2025-01)*
- 上海港拥有近350条国际航线，覆盖200多个国家和地区的700多个港口，港口连通度连续13年全球第一。  
  *Source: 上海市国资委(2025-01)*
- 2024年上海港货物吞吐量8.61亿吨，居全国第3。  
  *Source: 2024全国超亿吨港口货物吞吐量排名(2025)*
