# 04 — SEO TOPIC MAP & SEARCH-INTENT MATRIX

> Topic authority > keyword density. Every page must answer a real question with
> unique informational value. No pages created "because a keyword exists."

---

## A. TOPIC CLUSTERS (hub-and-spoke)

Each industry/product gets a topic cluster. Example for Electronics:

```
China Electronics Manufacturing (pillar hub)
├─ Shenzhen Electronics Manufacturing
├─ Dongguan Electronics Manufacturing
├─ Suzhou Electronics Manufacturing
├─ China Electronics Manufacturing Clusters
├─ Where Are Electronics Made in China?
├─ China PCB Manufacturing
├─ China EMS / Contract Manufacturing
├─ China Consumer Electronics
├─ China Electronics Components
├─ Shenzhen vs Dongguan Electronics
└─ China's Electronics Supply Chain
```

Repeat this structure per P0 industry: Power Batteries, Solar/PV, Construction
Machinery, Home Appliances, LED/Lighting, Machine Tools, NEV/ICV, Semiconductors,
Energy Storage, Textiles, Furniture, Footwear, Hardware, Medical Devices.

---

## B. SEARCH-INTENT MATRIX

Three intent families, each with a distinct page type:

### Informational (top of funnel)
- "Where are X made in China?"
- "Where is X manufactured in China?"
- "What are China's manufacturing clusters?"
- "Which cities manufacture X?"
- "Why is X manufacturing concentrated in Y?"

→ Page type: Product pages, Cluster pages, Research articles.

### Commercial Research (mid funnel)
- "Best region in China for X manufacturing"
- "China X manufacturing clusters compared"
- "China X manufacturing cities"
- "China X OEM manufacturing regions"

→ Page type: Comparison pages, Cluster comparison, City profiles.

### Buyer / Transactional (bottom of funnel)
- "How to source X from China"
- "Where should I source X in China?"
- "China manufacturing cluster for X"

→ Page type: Sourcing guides, Buyer-profile sections (NOT aggressive sales pages).

## D. AIO / AI-SEARCH OPTIMIZATION

Every important page must be machine-extractable:
- direct definitions, concise entity summaries, structured tables
- explicit relationships, source attribution, dates, confidence levels
- clear entity names and geographic relationships

Example extractable sentence:
> "Zhongshan's Guzhen town is one of China's major lighting manufacturing clusters."

Then explain evidence + limitations. **No fake FAQ blocks.**

## E. E-E-A-T SURFACE

Build (Phase 1 scaffolding, Phase 2 content):
- `/about/` `/methodology/` `/sources/` `/authors/`
- `/editorial-policy/` `/data-methodology/` `/corrections/`

Schema (structured data) — only appropriate types, never fake:
Organization, Article, Dataset, Place, DefinedTerm, Product, BreadcrumbList,
ItemList, WebPage. **Never** FAQPage/Review/AggregateRating with fabricated data.
